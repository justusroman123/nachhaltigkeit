# Bewertungsbogen für Muttersprachler (Plan, Phase 5) – Stand 11.11.2026

Ziel laut Plan: Muttersprachler bewerten die Übersetzung als „für Demo brauchbar“ (Skala 1–5, **mindestens 4**).
Reihenfolge: Ukrainisch, Arabisch, Englisch zuerst, Türkisch danach. Hörzeit: 3 Minuten erfundener Vortrag (`docs/vorfuehrung.md`).
Es werden nur erfundene Texte verwendet. Keine Namen der Bewertenden nötig.

Skala: 1 = unbrauchbar · 2 = schlecht · 3 = verständlich, aber mit klaren Fehlern · 4 = brauchbar für eine Demo · 5 = sehr gut
